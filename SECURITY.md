# Segurança e escopo

A biblioteca trabalha somente sobre o objeto fornecido; a CLI lê exclusivamente
o arquivo indicado e não acessa URLs. Use arquivos confiáveis e limites pequenos
quando o conjunto de combinações crescer. O limite de nós distingue busca
incompleta de inviabilidade comprovada; ele não constitui garantia de tempo.

Não use dados pessoais nos relatos de erro. Descreva o caso com identificadores
fictícios e a versão usada. A ferramenta não faz reservas, pagamentos ou decisões
operacionais por uma instituição.
